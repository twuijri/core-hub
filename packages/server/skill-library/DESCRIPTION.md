# Core Hub library

Skills that ship with Core Hub and are installed into every profile. Core Hub keeps each one up to
date while it is unchanged; a skill you edit is yours and is never overwritten (restore it from the
Skills page). The library can be switched off per profile.

مهارات تأتي مع Core Hub وتُثبَّت في كل بروفايل. يحدّثها Core Hub ما دامت كما هي، والمهارة التي
تعدّلها تصير لك ولا يكتب فوقها (تستعيدها من صفحة المهارات). ويمكن إيقاف المكتبة لكل بروفايل.
