## Description (max 10,000 characters)

Core Hub brings every AI agent you use into one place that you own.

Connect the app to the Core Hub server you host (your own machine, home server or VPS), or turn
on local mode and the app runs a hub on this PC, for you alone, listening only on this computer.

What you can do:
- Chat with streamed replies, see every tool call with its arguments and result, and answer the
  agent's approvals and questions as cards.
- Keep separate profiles, each with its own agent settings, memory and skills.
- Follow tasks on a board, run schedules and workflows, and see what each run did.
- Pair the app with your hub in seconds from the QR or link your hub shows.
- Get notified when a run finishes or an agent needs you; the unread count shows on the taskbar.
- Optionally share chosen folders with your agents through the local helper — off by default,
  read-only unless you allow writing.
- Use it in Arabic (right to left) or English.

Your data stays on the hub you choose. Core Hub is open source (Apache-2.0) and built around
Hermes Agent (MIT).

Local mode uses Hermes Agent on this PC. If it is not installed, the app offers Hermes's own
installer and shows it before it runs, or lets you continue without it.
