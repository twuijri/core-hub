# تحديد المحادثات: العلامة تبقى ظاهرة على كل صفّ محدَّد
المسؤول: twuijri · الفرع: fix/session-select-check · الحالة: review

## المشكلة والهدف
قال المالك (٢٠٢٦-٠٩-٢٣، بلقطة فيها «3 selected» وعلامة واحدة): «قلتلك قبل ان الصح ابيه يبقى
علشان اعرف وش الي اخترته وش الي ما اخترته … يتغير لون المربع بس مرات ما يكون واضح».

السبب: في وضع التحديد تحلّ خانة الاختيار محلّ مقبض السحب، ومقبض السحب **شفّاف حتى يمرّ
المؤشّر فوق الصفّ** (`.session-grip { opacity: 0 }`). فكانت العلامة تظهر على الصفّ الذي تحت
المؤشّر فقط، والباقي يتغيّر لونه بدرجة رمادية خفيفة.

## القرار والموافقات
- أثناء التحديد تبقى خانة كل صفّ ظاهرة (`.session-row[data-selecting='true'] .session-grip`)،
  محدَّدًا كان أو لا، فيُرى ما اخترته وما لم تختره.
- خلفية الصفّ المحدَّد صارت لون التمييز الخفيف (`accent-soft`) بدل الرمادي، لتُقرأ في
  الوضعين الفاتح والداكن.
