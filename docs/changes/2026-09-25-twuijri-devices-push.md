## المشكلة والهدف
عمليات `devices` السبع عشرة كلها 501، فلا شيء يستطيع أن يدفع إشعارًا إلى جوال أو حاسوب أو متصفح.
تطبيقات الجوال (#122/#125/#127، #120/#124/#128) وسطح المكتب (#111–#116) تعود إلى الفحص الدوري.
الهدف: سجل الأجهزة حسب العقد، وتوصيل ما يُكتب في صندوق الإشعارات إلى أجهزة الشخص عبر Web Push
(مفاتيح VAPID يولّدها المركز) وFCM وAPNs، مع احترام تفضيلات كل نوع وساعات الهدوء.
