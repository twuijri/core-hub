# سجلات التغيير

ملف لكل مهمة: `YYYY-MM-DD-<owner>-<topic>.md`. الأقسام إلزامية ويتحقق منها CI:

```markdown
# عنوان المهمة
المسؤول: <human> · الفرع: <branch> · الحالة: planned|in-progress|blocked|review|done

## المشكلة والهدف
## القرار والموافقات
## العقد (ما تغيّر في packages/contracts، أو «لا شيء»)
## الملفات والتأثير
## الفحوص (الأوامر ونواتجها الفعلية)
## المخاطر والرجوع
## التسليم والخطوة التالية
```
`done` تعني اكتمال النطاق المراجَع، لا النشر.
